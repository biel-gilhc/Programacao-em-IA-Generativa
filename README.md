# Curso de Programação em IA Generativa

Bem-vindo ao repositório do curso de **Programação em Inteligência Artificial Generativa** 🚀

Este material foi organizado para fornecer uma base sólida em IA moderna, cobrindo desde conceitos fundamentais de Inteligência Artificial até aplicações avançadas com modelos generativos, visão computacional e processamento de linguagem natural.

---

# Objetivos do Curso

Ao longo deste curso você irá:

* Compreender os fundamentos da Inteligência Artificial
* Aprender conceitos de Machine Learning e Deep Learning
* Trabalhar com Redes Neurais Artificiais
* Explorar Processamento de Linguagem Natural (NLP)
* Desenvolver aplicações com Visão Computacional
* Criar modelos personalizados com IA Generativa
* Aplicar técnicas modernas de desenvolvimento com IA

# Configuração do Ambiente

## 1. Clone o repositório

```bash
git clone <URL_DO_REPOSITORIO>
```

---

## 2. Crie um ambiente virtual

### Linux / MacOS

```bash
python -m venv venv
source venv/bin/activate
```

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

---

## 3. Instale as dependências

```bash
pip install -r requirements.txt
```
